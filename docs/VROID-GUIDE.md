# VRoid로 3D 캐릭터 만들기 (9명)

3D 사무실의 이름 있는 9명을 VRoid Studio(무료, Windows)로 만들어 넣는 방법이다. 규격과 동작은 DESIGN 13장 "3D 캐릭터".
파일을 넣기 전까지 화면은 코드로 만든 임시 인형을 쓴다. 한 명씩 넣어도 된다.

## 넣는 법

1. VRoid Studio에서 **새로 만들기 → 여성 기본 모델**로 시작한다. 기준 그림은 `assets/portraits/<직원 ID>.webp`(Discord 봇 프로필과 같은 사진)를 옆에 띄워 두고 본다.
2. 아래 표대로 머리·눈·옷을 맞춘다. 색은 VRoid 색 고르기 창에 hex 값을 그대로 넣는다(기본색 / 그림자색).
3. **촬영·내보내기 → 내보내기 → VRM 내보내기**. VRM 1.0을 고른다(0.0도 된다).
   - 폴리곤 줄이기: 머리카락 "줄임", 텍스처 묶기 해상도 **2048**. 파일 하나 30MB 이하.
   - 메타 정보 아바타 이름은 캐릭터 이름(예: 한주아). 나머지는 기본값.
4. 파일 이름을 **`<직원 ID>.vrm`**으로 저장해서 `C:\ai-office\office\assets\models\`에 넣는다(폴더가 없으면 만든다).
5. 사무실 화면을 새로고침한다. 재시작도 코드 수정도 필요 없다. 모델을 못 읽으면 코드 인형이 그대로 나온다(브라우저 콘솔에 이유가 찍힌다).

공통 옷: 검은 재킷(블레이저) `#23252B` / 그림자 `#121318`, 흰 셔츠 `#F7F7F9`(깃 세움), 검은 무릎 길이 치마 `#26272D`, 검은 스타킹, 검은 굽 낮은 구두. 피부 기본값(밝은 쪽). 표정은 기본, 눈은 표의 홍채 색.
