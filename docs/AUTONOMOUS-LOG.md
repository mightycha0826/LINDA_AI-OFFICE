# 자율 진행 기록 (2026-10-16, 주인 부재 중)

주인이 "3시 반까지 주도적으로 계속 진행"하라고 한 동안 Claude Code가 스스로 정한 것들이다. 원래 작업 방식은 단계마다 시작·끝에 확인을 받는 것이라, 여기 적힌 결정은 **돌아와서 한 번 훑어보고 고칠 것이 있으면 알려 주면 된다.** 모든 결정은 DESIGN.md와 `설계 변경 대기 목록.md`에도 반영했다.

- **한 것**: 3단계 Discord → 4단계 Git 고양이 → 5단계 사무실 화면 → 6단계 회고와 학습. 단계마다 로컬 커밋(푸시 안 함). 16장의 1~6단계 코드가 모두 들어갔다.
- **테스트**: 384개 통과, 타입 검사 통과, `npm run sim` 통과. 실제 Discord·GitHub·Claude·Codex 연결은 아직 확인하지 않았다(0단계 검증과 토큰·채널 준비가 먼저).
- **돌아와서 결정할 것** (아래 표에서 굵게 표시한 것 위주):
  1. 화면 조합 번호: 답이 없어 **조합 1**로 시작함 (R)
  2. 막힘 표시를 빨간 느낌표 대신 **point 색 경고 아이콘**으로 함. 12장 안에서 두 규칙이 부딪혔음 (S)

  5. 4단계: 고양이를 별도 프로세스가 아니라 모듈로 둔 것, 푸시 실패 때 티켓 상태를 바꾸지 않는 것 (J, K)
- **켜는 법**: `docs/RUNNING.md`
- **주인이 할 일 모음**: 각 단계 끝의 "주인이 할 일" (Discord 봇·채널, gitleaks·GitHub 토큰, Tailscale 주소, 헤르메스 폴더, 캐릭터 그림)

4. Windows 자격 증명 관리자에 남은 GitHub 로그인은 지우기를 권한다(고양이는 없어도 동작한다).

### 실제 연결 전에 주인이 할 일 (3단계 Discord)

1. Discord 개발자 포털에서 회사 시스템 봇을 만들고 비공개 서버에 초대한다(권한: 메시지 보내기, 스레드 만들기, 메시지 관리, 애플리케이션 명령). **Message Content Intent는 켜지 않는다.**
2. 채널 5개(#비서실, #결재함, #보고, #막힘, #사무실-대화)를 만들고, #사무실-대화에 웹훅을 하나 만든다.
3. `C:\ai-office\data\config.json`에 `discord.guildId`와 `discord.channels`(채널 ID 5개)를 적는다.
4. `C:\ai-office\data\secrets.json`에 `discordToken`, `mirrorWebhookUrl`을 적는다(`internalApiToken`은 처음 실행 때 자동 생성).
5. 헤르메스 `config.yaml`의 `mcp_servers`에 `node C:/ai-office/office/packages/orchestrator/src/mcp/main.ts`를 등록한다.
6. `npm start`(또는 `pm2 start ecosystem.config.cjs`)로 띄운다.
