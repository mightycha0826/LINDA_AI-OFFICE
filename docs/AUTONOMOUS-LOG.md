### 4단계 실제 연결 전에 주인이 할 일

1. gitleaks 8.19 이상을 설치한다(`winget install gitleaks` 등). 없으면 고양이는 푸시하지 않는다.
2. GitHub에서 **등록할 저장소에만** Contents 쓰기 권한이 있는 세분화된 토큰(fine-grained)을 만들어 `secrets.json`의 `githubToken`에 넣는다.
3. main에 "PR 필수" 보호 규칙이 있으면 끄거나 토큰에 예외를 준다(11장).
4. Windows 자격 증명 관리자에 남은 GitHub 로그인은 지우기를 권한다(고양이는 없어도 동작한다).

### 실제 연결 전에 주인이 할 일 (3단계 Discord)

1. Discord 개발자 포털에서 회사 시스템 봇을 만들고 비공개 서버에 초대한다(권한: 메시지 보내기, 스레드 만들기, 메시지 관리, 애플리케이션 명령). **Message Content Intent는 켜지 않는다.**
2. 채널 5개(#비서실, #결재함, #보고, #막힘, #사무실-대화)를 만들고, #사무실-대화에 웹훅을 하나 만든다.
3. `C:\ai-office\data\config.json`에 `discord.guildId`와 `discord.channels`(채널 ID 5개)를 적는다.
4. `C:\ai-office\data\secrets.json`에 `discordToken`, `mirrorWebhookUrl`을 적는다(`internalApiToken`은 처음 실행 때 자동 생성).
5. 헤르메스 `config.yaml`의 `mcp_servers`에 `node C:/ai-office/office/packages/orchestrator/src/mcp/main.ts`를 등록한다.
6. `npm start`(또는 `pm2 start ecosystem.config.cjs`)로 띄운다.
