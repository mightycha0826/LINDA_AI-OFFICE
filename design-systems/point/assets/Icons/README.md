# Icons

Google Material Symbols Rounded, 채움 0, 굵기 400 (Apache License 2.0). 원본 SVG는 검정 한 가지 색이고, 화면에서는 아이콘 글꼴(`material-symbols-rounded` 클래스)로 써서 `color`로 칠해요.

| 아이콘 | 쓰는 곳 | 색 토큰 |
| --- | --- | --- |
| add | 추가 버튼, 떠 있는 버튼 | on-primary |
| arrow_upward | 입력줄 보내기 | on-primary |
| check | 켜진 체크 | on-primary-icon |
| check_circle | 성공 토스트 | toast-primary-icon |
| checklist | 할 일 탭, 빈 목록 | point-icon (빈 목록) |
| calendar_month | 달력 탭 | 탭 색 |
| bar_chart | 기록 탭 | 탭 색 |
| settings | 설정 탭 | 탭 색 |
| warning | 마감 지남 알림 | point-icon |
| info | 안내 알림 | primary-icon |
| error | 오류 배지, 오류 문구 | danger |
| delete | 삭제 버튼 | danger |
| refresh | 다시 시도 | ink |
| cloud_off | 오프라인, 새로고침 실패 | danger / toast-icon |
| progress_activity | 로딩 | primary-icon |
| more_horiz | 더 보기 | ink |
| light_mode, dark_mode | 테마 전환 | ink |

로고는 아직 없어요. 앱 이름은 Paperlogy 700으로 글자만 씁니다.
