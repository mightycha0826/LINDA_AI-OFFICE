# 포인트 디자인 시스템

회색 위에 조합색 두 개만 쓰는 디자인 시스템이에요. 기본 조합 10개 중 하나를 앱마다 골라 쓰고, 나머지는 모두 회색이 맡아요. 할 일 앱으로 다듬었지만 다른 서비스에도 같은 규칙으로 씁니다.

## 원칙

- **포인트는 두 색뿐.** 첫 번째 조합색(primary)은 주 버튼, 켜진 체크, 진행 막대, 지금 탭에만. 두 번째 조합색(point)은 오늘 표시와 마감 경고에만.
- **알림은 회색 면.** 알림, 토스트, 배지는 색 면을 깔지 않고 회색 면 위에 작은 색 아이콘이나 점만 둬요.
- **빨강은 오류와 삭제에만.** 오류 배지는 색 점이 아니라 느낌표 아이콘이라, 분홍·다홍 조합에서도 경고 점과 헷갈리지 않아요.
- **다크는 짙은 회색.** 완전한 검정이 아니고, 조합색을 섞지도 않아요. 바탕 < 하단 영역 < 할 일 행 순서로 한 단계씩 밝아져요.
- **대비는 자동.** 조합색이 바탕에서 묻히면 3:1(글자는 4.5:1)이 될 때까지 라이트는 어둡게, 다크는 밝게 밀어요.

## 말투

짧고 다정한 존댓말 해요체. 지금 상태와 할 수 있는 일을 바로 말해요.

- 할 일이 없어요 / 아래 입력줄에 적으면 바로 추가돼요
- 불러오지 못했어요 / 인터넷 연결을 확인해 주세요
- 버튼은 동사 하나: 추가, 삭제, 다시 시도, 되돌리기
- 느낌표, 이모지, "죄송합니다"는 쓰지 않아요.

## 색

토큰 이름은 역할이에요(`primary`, `row`, `ink`). 이 시스템에 저장된 값은 **조합 1 · 코발트와 주황**으로 계산한 기본 테마예요. 다른 조합은 `Point.theme(번호, 모드)`가 같은 규칙으로 계산해요.

계산 규칙은 이래요.

1. 회색은 조합마다 정해진 온도(차가운·중간·따뜻한)의 세트를 써요. 라이트는 흰 바탕, 다크는 `#1B1E24`·`#1E1E1E`·`#1F1D1A` 바탕이에요.
2. 버튼 면 `primary`는 흰 글자가 4.5:1이 되도록 보정해요(라이트는 필요할 때만 어둡게, 다크는 그 한도까지 밝게). 그래서 버튼 글자는 어떤 조합에서도 흰색이에요. 켜진 체크와 점은 `primary-icon`(행 위 3:1)으로 따로 계산해요.
3. 아이콘·점은 `row` 위 3:1, 글자로 쓰는 조합색은 `surface` 위 4.5:1.
4. 다크에서 조합색이 너무 쨍하면 `Point.theme(i, 'dark', { mute: 0.2 })`처럼 채도만 낮춰요. 기본은 0이에요.

## 상태

모든 누를 수 있는 것은 같은 규칙을 따라요(`state-*` 토큰).

- 호버: 라이트 8% 어둡게, 다크 8% 밝게
- 눌림: 16%, 그리고 `scale(.96)`
- 포커스: 2px 틈을 두고 `focus` 색 2px 테두리
- 비활성: 투명도 0.4
- 로딩: 버튼 글자를 "저장 중"으로 바꾸고 아이콘을 돌림표로

## 빈 화면·로딩·오류

**목록이 있으면 목록을 지켜요.** 새로고침은 화면 맨 위 4px 진행 막대(`RefreshBar`), 새로고침 실패는 입력줄 위 토스트(`Toast`). 화면이 갑자기 비지 않아요.

**목록이 없으면 가운데 아이콘 원.** 빈 목록(두 번째 색 아이콘), 첫 로딩(첫 번째 색 아이콘), 저장본 없는 오프라인(빨강 아이콘 + 다시 시도) 모두 `EmptyState`. 첫 로딩과 오프라인에서는 입력줄을 비활성으로 둬요.

## 모바일 구조

하단 탭 네 개(할 일·달력·기록·설정). '할 일' 탭에서만 탭 바로 위에 입력줄(`Composer`)이 붙어 하단 영역 116px을 이뤄요. 키보드가 올라오면 탭은 사라지고 입력줄만 키보드 위에 남아요. 다른 탭에서 추가는 오른쪽 위 원형 버튼(`IconButton`)이에요. 달력의 오늘은 primary 테두리, 고른 날은 `ink` 칸이에요.

## 아이콘

Material Symbols Rounded(채움 0, 굵기 400)만 써요. 쓰는 아이콘 18개와 각각의 색 토큰은 자산의 Icons 그룹에 있어요. 아이콘만 있는 버튼에는 꼭 `aria-label`.

## 글자

Paperlogy 한 가족, 400과 700 두 굵기. 아이콘은 Google Fonts의 Material Symbols Rounded(채움 0, 굵기 400)를 씁니다. 숫자가 줄을 맞춰야 하는 곳(완료 수)은 `tabular-nums`.

## 간격과 모서리

4px 단위(`space-*`). 모바일 화면 좌우는 `space-5`(20px). 할 일 행 56px, 행 사이 8px. 모서리는 입력창 14px, 행 18px, 카드 28px, 버튼·배지는 완전한 알약(`radius-full`).

## SvelteKit에서 쓰기

Svelte 5 컴포넌트 묶음(`point-svelte`)이 따로 있어요. `src/lib/point/`에 넣고 `theme.ts`, `point.css`, `tokens.css`를 쓰면 돼요. 아래는 그 묶음 없이 CSS만 쓰는 방법이에요.


1. `tokens.css`와 `components/bundle.css`를 전역 스타일로 가져와요. 컴포넌트는 `pt-` 접두사 CSS 클래스라 프레임워크와 상관없어요.
2. `components/bundle.js`의 `Point.theme(조합번호0부터, 'light' | 'dark')`이 CSS 변수 값을 돌려줘요. 서버에서 계산해 `<html style>`에 넣으면 깜빡임이 없어요.
3. `Point.apply(document.documentElement, 2, 'dark')`처럼 요소 하나에 바로 입힐 수도 있어요. `data-theme`도 같이 바뀌어 호버 방향이 맞춰져요.
